## 1. The cycle ruling: full-flow staged combustion, not Brayton

The discriminator is measured, not aesthetic:

- **Open cycle (Brayton) already exists and is measured.** The deployed
  parser is an open-cycle stack — intake→compress→combust→exhaust, each
  station refines, nothing returns. It binds at 1.000 after one layer,
  holds erasure-free to the exit — **and computes nothing derived**
  (parity at chance everywhere). Open cycle binds without deducing.
- **The round-trip measured 0.011** because deduction arriving AFTER
  binding hardened cannot revise it. The compile-side failure mass is
  bindings that need implications-during-binding.
- **Full-flow's defining property:** nothing is dumped — both streams
  pass through preburners and ALL of it enters the main chamber.
  Compiler analog: every station's partial deduction re-enters the
  shared state the other stations read, rather than being passed
  forward and forgotten. Closed cycle is the only topology where
  deduction's pressure reaches binding while it is still soft.
- **The honest cost:** closed cycle is where Fire 2's violence lived.
  But Seam-1's contraction is CONFIRMED (thermometer cooling
  geometrically, manifold trend flipping positive, the blind routing
  prediction printing TRUE) — recirculation is survivable with the
  physiology the re-light proved.

## 2. The architecture: stations that are themselves loops

The depth budget is the binding constraint, harder than the cycle fork:

- The measured clock: ~3.5 breaths per implication layer (engine-clock,
  deployed ruler). A fixed station count fixes deduction depth: four
  stations buy ~one implication layer. The frontier census says the
  compiler's failures are exactly the bindings needing implications.
  **The pure jet is refuted before it is built.**
- **The resolution is the compressor's own anatomy:** multiple untied
  stages, each doing bounded work, flow passing through all; each stage
  internally has rotor and stator doing distinct things. Therefore:
  - **Untied stations** → differentiation by construction (the thing
    three fires could not get from tied weights; Fire 1's failure was
    differentiation refusing to emerge across tied weights under
    explicit gradient demand).
  - **Station-local loops** → depth within station (bounded iteration,
    tied only within a station's own small recurrence).
  - **Shared soft state** → full-flow recirculation (every station
    reads and writes it; nothing exits until the state settles).
- **Why the three-pole map is complement, not refutation:** dead /
  violent / contracted-wrong were all measured inside GLOBALLY tied
  recurrence. Station-local loops with untied station weights is
  unmapped territory. This bet enters it by the front door.
